# Contributing to Owl

Thank you for your interest in contributing to Owl. We welcome contributions from the community.

### Getting Started

We recommend starting by opening an issue to discuss any significant changes or new features. This helps ensure your contribution aligns with the project's direction and avoids duplicated effort.

Small fixes, documentation improvements, and bug reports are always appreciated and can be submitted directly as pull requests.

### Development Guidelines

- Follow the existing code style and architecture patterns
- Maintain clean, readable code
- Add or update tests when appropriate
- Ensure changes are focused and well-documented

Owl uses Effect-TS heavily and follows FMCF principles internally. We value maintainability and thoughtful design.

### Questions or Feedback

Feel free to open a Discussion or reach out directly.

We appreciate every contribution, big or small.
